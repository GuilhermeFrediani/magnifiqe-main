Flow: 1. CacheAligner detects volatile content (UUIDs, timestamps, JWTs) 2. ContentDetector determines content type 3. CCR hierarchy applies appropriate compression level 4. - `src/compression/ccr-hierarchy.js` — js; 235 lines; Stack Perfeita MCP — CCR Hierarchy (Compression-Compression-Restore) Unified 4-level compression pipeline: Level 1 (Lossless): strip HTML comments, collapse whitespace Level 2 (Structural): clip head/tail, preserve structure markers Level 3 (Semantic): extract key points, drop redundancy Level 4 (Aggressive): drop entire sections by priority Combines Headroom's content routing with Magnifiqe's existing minifyTokens/clipText.
